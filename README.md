# Portfolio — Thomas (BeThom)

Bienvenue sur le dépôt du site portfolio moderne et réactif pour **Thomas (BeThom)**, Graphiste / UI-UX Designer. Ce site présente le parcours de Thomas, ses derniers articles de blog, ses projets récents ainsi qu'un formulaire de contact interactif.

---

## 🚀 Aperçu du Projet

* **Design épuré & moderne** : Mise en page soignée axée sur la typographie et la lisibilité.
* **100% Responsive** : Adapté pour les smartphones, tablettes et écrans d'ordinateurs (approche *Mobile-First*).
* **Téléchargement de CV** : Fonctionnalité d'export / téléchargement direct du CV au format PDF via le bouton dédié.
* **Effets visuels personnalisés** : Avatar avec ombre portée personnalisée (`#EDF7FA`) et liens nettoyés.

---

## 🛠️ Technologies Utilisées

* **HTML5** : Structuration sémantique et accessibilité.
* **CSS3 (Vanilla)** : Stylisation sur-mesure, Flexbox, CSS Grid et *Media Queries* pour la réactivité.
* **JavaScript (Vanilla)** : Gestion du téléchargement dynamique du CV.
